# NSE Derivatives Monitor

An on-demand monitoring workflow for NSE derivatives (NIFTY / BANKNIFTY / FINNIFTY /
MIDCPNIFTY + HDFCBANK / RELIANCE), built around the three layers professional desks track:

| Layer | What it watches | Sources |
|---|---|---|
| **L1 Positioning** | Participant-wise OI (FII / DII / Client / Pro), FII-DII cash flows | NSE archives CSV, NSE FII/DII API |
| **L2 Volatility** | ATM IV, IV rank, India VIX rank, IV term structure, 25Δ skew | NSE F&O bhavcopy (Black-76 IV), Yahoo Finance |
| **L3 Microstructure** | PCR, OI walls (max-OI strikes), max pain, futures basis | Bhavcopy chain, live option-chain-v3 (best effort) |

Runs automatically every weekday evening on GitHub Actions, publishes a **dashboard**
and **trends page** to GitHub Pages, **alerts** on significant shifts, and commits all
history back to the repo. All data is public — no API keys needed for the data itself.

## Quick start

```
python nse_deriv_monitor.py
```

or double-click / schedule `run.cmd` (runs the full monitor and writes reports).

### Options

```
python nse_deriv_monitor.py                  # full run: industry layers, both indices
python nse_deriv_monitor.py --symbols NIFTY  # single index
python nse_deriv_monitor.py --no-fetch       # re-render from local DB (no network)
python nse_deriv_monitor.py --days 30        # how far back to fill participant OI (default 21)
python nse_deriv_monitor.py --data-dir D:\nse-data --out-dir D:\nse-reports
```

## What you get

- **"What changed" block** at the top of every report — a one-line headline plus
  deltas vs the previous session (FII positioning d/d & w/w, cash flows, VIX level
  and rank, per-symbol spot %, IV, PCR and wall moves)
- **Console report** (the three layers, ready to read over a coffee)
- **JSON summary** in `output/monitor_YYYYMMDD_HHMM.json` (machine-readable for further analysis)
- **HTML dashboard** in `output/monitor_YYYYMMDD_HHMM.html` (open in browser)
- **Trends page** in `output/trends.html` — 12-month charts (participant positioning,
  option PCR, India VIX vs realized vol and ATM IV snapshots), generated by `make_trends.py`
- **Alerts** — `send_alerts.py` evaluates `alerts_config.json` rules and delivers via
  Telegram and/or a GitHub issue; audit trail in `output/alerts.log`
- **SQLite history** in `data/nse_monitor.db` — grows with every run:
  - `participant_oi` — daily per-participant futures/options OI (FII, DII, Client, Pro)
  - `cash_flow` — FII/DII cash-market buy/sell/net
  - `iv_snapshot` — daily per-symbol ATM IV, skew, PCR, walls, max pain, term structure, basis

## Alerts

Rules live in `alerts_config.json` (thresholds are yours to tune):

| Rule | Fires when | Default threshold |
|---|---|---|
| `fii_futures_shift` | FII index-futures net moves w/w | ±50,000 contracts |
| `vix_rank_extreme` | India VIX 1y percentile rank extreme | ≥85 (fear) or ≤15 (complacency) |
| `iv_rv_gap` | NIFTY ATM IV vs realized vol (21d) gap | ±5 vol pts |
| `fii_option_pcr_extreme` | FII index-options PCR extreme | ≥1.5 or ≤0.6 |

Per-rule **cooldowns** (default 5–7 days) prevent repeat spam while a condition persists.
Duplicate suppression uses `data/alert_state.json`.

**Delivery channels**
1. **GitHub issue** (default, no setup): fires create an issue labeled `alert` and
   GitHub emails you. Permission `issues: write` is already granted in the workflow.
2. **Telegram** (optional): create a bot with @BotFather, get your chat id, then:
   ```
   gh secret set TELEGRAM_BOT_TOKEN -R posu303-tech/nse-deriv-monitor
   gh secret set TELEGRAM_CHAT_ID   -R posu303-tech/nse-deriv-monitor
   ```
   Without these secrets the issue channel is used instead.

**Test the pipeline anytime:**
```
gh workflow run monitor.yml -R posu303-tech/nse-deriv-monitor -f test_alert=true
```
or locally: `python send_alerts.py --test` (dry run: `--dry-run`).

## Trends page

`make_trends.py` reads the SQLite history and writes a self-contained
`output/trends.html` (inline SVG + vanilla JS, no CDN — works offline):

1. **Participant net position** in index futures over ~12 months (FII/DII/Client/Pro)
2. **Participant option positioning PCR** over time
3. **Volatility**: India VIX vs NIFTY realized vol (21d), plus ATM IV snapshots
   for every tracked symbol (dots accumulate with each run)
4. **Download archive**: every weekly digest and rollover special, dated and linked
   (files are copied to the published site on each run)

The published copy lives at the dashboard URL + `/trends.html`.

## Monthly rollover special (expiry week)

`rollover_special.py` activates automatically within **7 calendar days of the monthly
futures expiry** (and regenerates on every run inside the window, so the page tracks
the roll daily). It produces `output/rollover.html` + dated copies:

- **Current state per symbol**: roll %, 5-session roll change, carry spread (pts and %),
  5-session near/next OI changes, rule-based notes
- **Roll trajectory**: roll % by session for the last ~10 sessions (the classic
  month-end acceleration curve)
- **Cycle history**: final roll % and roll % at the same days-to-expiry for the last
  4 completed cycles, with averages (sell-side style) — e.g. "NIFTY at T-13: 12% now
  vs 15% 3-cycle average". Rebuild deeper history anytime with
  `-f fut_backfill_days=160` (or a one-off local `--backfill-fut 160`).
- **Positioning into expiry** (participant 5-session changes) and **vol into expiry**
  (India VIX rank, ATM IV term structure per symbol)

**Delivery** (per `alerts_config.json` → `"rollover_special"`) fires twice per cycle:
when the window opens ("X days to expiry") and on the last session ("final roll").
GitHub issue labeled `rollover` (emails you) + Telegram if secrets are set.

Manual run (any day):
```
gh workflow run monitor.yml -R posu303-tech/nse-deriv-monitor -f force_rollover=true
```

## Weekly digest (Fridays)

`weekly_digest.py` runs automatically on the Friday evening workflow run (and can be
forced any day) and produces `output/weekly_YYYYMMDD.html` + `output/weekly.html`:

- **Positioning**: 5-session changes in every participant's net index futures and PCR
- **Cash**: 5-day cumulative FII/DII flows
- **Volatility**: India VIX change / week range / rank; per-symbol IV + PCR changes
- **Rollover context** (from daily futures settle + OI):
  - **Roll %** = next-month OI ÷ (near + next OI) — positions carried forward
  - **Roll spread** = next − near settle (positive = carry premium) and its weekly change
  - 5-session near/next OI changes and rule-based notes ("roll-in accelerating",
    "positions carried to next month", "net unwinding", thin-contract warnings)

**Delivery** is controlled by `alerts_config.json` → `"weekly_digest"`:
- `deliver_github_issue: true` (default) → opens a Friday issue labeled `digest`
  (GitHub emails you — a ready-made weekly email digest)
- `deliver_telegram: true` (default, if secrets set) → sends the text digest to Telegram

Manual run (any day):
```
gh workflow run monitor.yml -R posu303-tech/nse-deriv-monitor -f force_weekly=true
```

Rollover history is seeded from bhavcopies and extends daily. To backfill more:
```
gh workflow run monitor.yml -R posu303-tech/nse-deriv-monitor -f fut_backfill_days=60
```

## How the data pipeline works

```
NSE archives (participant OI CSV) ──────► participant_oi table ─┐
NSE API (FII/DII cash) ─────────────────► cash_flow table ──────┤
                                                                ├──► report (console/JSON/HTML)
NSE bhavcopy (option chain EOD) ─┐                              │
   or live option-chain-v3 ──────┴──────► iv_snapshot table ────┘
Yahoo Finance (India VIX, NIFTY) ───────► vol context (rank, realvol)
```

**Reliability design:** NSE's live APIs throttle aggressively (they return
`HTTP 200` with an *empty* payload instead of 429). The tool detects an empty
chain response, backs off, and falls back to the daily **bhavcopy** on
`archives.nseindia.com`, which publishes the full EOD option chain (OI,
settlement prices, volumes) and is far less throttled. IV is then computed
locally with Black-76 from settlement prices (risk-free 6.5%).

Notes:
- The bhavcopy for day *T* is published after market close (~18:00–19:00 IST).
  A run at 10:00 IST therefore shows data as of the previous session.
- The live chain, when it responds, is marked `[live]` and its IVs come from
  NSE's own published IVs.
- IV rank (`iv_rank_local`) needs ~8 sessions of history to appear, and a few
  weeks to be genuinely informative. India VIX rank (1y) is available from day one.

## Scheduled / recurring use

### Cloud (GitHub Actions + Pages) — this repo is already set up

- **Repo:** https://github.com/posu303-tech/nse-deriv-monitor (public)
- **Public dashboard:** https://posu303-tech.github.io/nse-deriv-monitor/
- **Schedule:** weekdays at 14:45 UTC (~20:15 IST) via `.github/workflows/monitor.yml`
- **Every run:** publishes the latest report to the dashboard, and commits the
  SQLite history (`data/`), reports (`output/`) and console log back to `main`.

Manual controls (needs `gh` CLI authenticated, or use the Actions tab on GitHub):

```bash
# run once right now
gh workflow run monitor.yml -R posu303-tech/nse-deriv-monitor

# one-off: seed a year of participant-OI history (check progress in the Actions log)
gh workflow run monitor.yml -R posu303-tech/nse-deriv-monitor -f backfill_days=365

# watch / inspect runs
gh run list -R posu303-tech/nse-deriv-monitor
gh run view <run-id> -R posu303-tech/nse-deriv-monitor --log
```

To change the schedule, edit the `cron:` line in `.github/workflows/monitor.yml`
(UTC times; IST = UTC + 5:30). Keep it after ~18:00 IST so that the bhavcopy and
participant OI archives for the day are already published.

### Local (optional)

Register a Windows scheduled task to run the monitor on weekdays after
NSE publishes EOD data (e.g. 19:30 IST):

```powershell
schtasks /Create /TN "NSE Deriv Monitor" /TR "\"C:\Users\hp\Toolbox\NSE-Deriv-Monitor\run.cmd\"" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 19:30 /F
```

Remove it with: `schtasks /Delete /TN "NSE Deriv Monitor" /F`

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| `live chain unavailable (throttled)` | Normal (especially from cloud runners). The tool uses bhavcopy instead. For a live intraday chain, open nseindia.com/option-chain in a browser. |
| Participant OI missing for latest day | NSE publishes the archive after EOD. The scheduled 20:15 IST run catches it. |
| `india_vix_cache.json` stale | Cache auto-refreshes after 20h; check internet access to Yahoo Finance. |
| Wrong day's data | Check the `snapshot <date>` line — bhavcopy is always the *latest published* session. |
| Workflow fails at "Connectivity smoke test" | NSE/archives unreachable from the runner that time; check the smoke-test log, usually transient. |
| Dashboard not updating | Check the latest Actions run; Pages deploys ~1 min after the run completes. |

## Extending

- **More indices**: pass `--symbols` with any index that has derivatives (e.g. `MIDCPNIFTY`, `FINNIFTY` for live; bhavcopy covers all).
- **History is yours**: query `data/nse_monitor.db` directly for backtests of
  positioning/IV signals, or to build charts.
- **Thresholds/alerts**: the JSON output is designed to be consumed by a simple
  script that messages you when e.g. FII net futures move more than X contracts
  week-over-week, or India VIX rank crosses a level.
